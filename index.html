The day is the unit

Every run is one service day, 04:00 to 24:00. The strip draws the peak bands, the day's load as a single trace, disruptions as bars and now as a needle. Point at a later hour and the day runs to it.

The service-day strip, as it sits in the dock.

Break it, then watch it recover

Eight kinds of failure, from a station closure to a bridge outage. Vehicles hold at the barrier, riders reroute or strand, replacement buses run the gap, and the network is scored on how well it came back.

A segment closure: the vehicle holds, and replacement buses run the closed stretch.

Every number comes from the run

Occupancy, waits, fares, cost recovery and subsidy are counted from the simulation itself, never scripted in. Open a report and a figure traces back to the state that produced it.
